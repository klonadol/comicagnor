Оригиналы неизменяемы. Сведения в черновиках не становятся каноном автоматически. При расхождении версий учитываются явные решения автора.

## Авторские решения из беседы

- Андрей переименован в **Олега**.
- Таня — **приёмная дочь Нихиль**, а не биологическая дочь или внучка.
- Высокий для гномов рост Олега — нормальное редкое исключение.
- Пустыня на западе формально относится к Нард-Аку, но государство не стремится осваивать опасную и бесполезную территорию.
- Агнор — центральный герой; новая предыстория описана в `03_characters/CHAR-AGNOR.md`.
- Запланирована романтическая линия Агнор/Таумиэль; Олег без обязательной пары.
- Прежние романтические комбинации из черновика не утверждены.

# Детали и долгосрочная непрерывность

Категории (создаются карточки по мере появления фактов):
- `events/` — факты событий за кадром;
- `objects/` — предметы и цепочка владельцев;
- `secrets/` — тайны, кто что знает;
- `relationships/` — отношения и их динамика;
- `promises/` — обещания, обязательства, долги;
- `foreshadowing/` — зацепки и их последующие раскрытия.

Использовать `FACT-0001`, `FACT-0002` и т. д.; шаблон — `FACT_TEMPLATE.md`. Не придумывать дату/координаты там, где они не определены.

**Значимый факт:** пример с покупкой Олегом камня души пять лет назад из предыдущего обсуждения был иллюстрацией формата, а не событием канона.

# Агнор — визуальный референс

**ID:** CHAR-AGNOR

## Внешность (полный текст из канонического источника)

парень лет 20 с накачанной стройной фигурой, рыжие волосы до плеч,
темно-зеленые глаза, почти всегда хмурый суровый взгляд. на груди на месте сердца
черно-зеленая сфера, под одеждой не видно.

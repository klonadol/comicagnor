# Эфиль — визуальный референс

**ID:** CHAR-EPHIL

## Внешность (полный текст из канонического источника)

красивая и привлекательная девушка ангел с высокой спортивной фигурой.
У Эфиль короткие черные волосы и оранжевые глаза. У Эфиль шесть ангельских
крыльев и пылающий нимб.

# Галгалиэль — визуальный референс

**ID:** CHAR-GALGALIEL

## Внешность (полный текст из канонического источника)

небесно красивая девушка ангел с стройной и привлекательной фигурой с
привлекательными округлостями. Галгалиэль ангел с шестью крыльями и золотистыми
нимбом, золотистыми длинными волосами и золотистыми глазами. Носит открытые
ципао, или любую одежду с большим количеством открытой кожи из-за своего
недостатка, не на публике носит купальники.

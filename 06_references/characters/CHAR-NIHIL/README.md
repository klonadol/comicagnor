# Нихиль — визуальный референс

**ID:** CHAR-NIHIL

## Внешность (полный текст из канонического источника)

Высокая и красивая девушка ангел с небесной красотой. Обладает восемью
ангельскими крыльями, длинными белыми волосами до пояса и глазами, похожими на
космическую туманность.

# Олег — визуальный референс

**ID:** CHAR-OLEG

## Внешность (полный текст из канонического источника)

Коренастый крепкий парень ростом 165 см, что является почти рекордным
ростом среди гномов. Имеет красивое лицо, каштановые волосы и зелёные глаза с
золотым кольцом вокруг зрачков.

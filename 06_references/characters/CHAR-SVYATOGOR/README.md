# Святогор — визуальный референс

**ID:** CHAR-SVYATOGOR

## Внешность (полный текст из канонического источника)

Очень большой мужчина ростом 230 см. Коричневые волосы, карие глаза. Несмотря на
огромный размер и силу, имеет добродушный внешний вид. У него медвежьи уши.

# Сильви — визуальный референс

**ID:** CHAR-SYLVI

## Внешность (полный текст из канонического источника)

Высокая и красивая эльфийка с привлекательными округлостями, с иссиня-
чёрными волосами и зелёными глазами, вокруг зрачков которых находится розовое
кольцо. Её внешность сочетает благородство королевы и лёгкую озорную
энергичность. Одета в лёгкие синие ткани.

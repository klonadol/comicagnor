# Таня — визуальный референс

**ID:** CHAR-TANYA

## Внешность (полный текст из канонического источника)

Высокая, сексуальная девушка небесной красоты. Длинные белые волосы,
голубые глаза, нимб и три пары ангельских крыльев. Носит откровенные ципао
подчёркивающие её фигуру.

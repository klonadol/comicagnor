# Таумиэль — визуальный референс

**ID:** CHAR-TAUMIEL

## Внешность (полный текст из канонического источника)

Высокая и очень красивая сексуальная эльфийка благородной внешности.
Имеет иссиня-чёрные волосы и зелёные глаза. Обычно одевается в темно-зеленую
одежду.

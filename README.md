# Агнор — цветная вертикальная манхва

Рабочий репозиторий авторского мира **Агнор** и производства манхвы.

> Статус: подготовка канона и визуальной библии. Сценарий глав и иллюстрации пока не утверждены.

## Навигация

| Раздел | Назначение |
| --- | --- |
| `01_sources/` | Реестр исходных документов и история версий; оригиналы никогда не переписываются |
| `02_world/` | Мир, география, история, государства и система аспектов |
| `03_characters/` | Персонажи и отношения |
| `04_facts/` | События, объекты, тайны, обещания, предзнаменования |
| `05_story/` | Общая сюжетная структура, арки и хронология |
| `06_references/` | Утверждённые визуальные референсы с постоянными ID |
| `07_production/` | Сценарии глав, раскадровка, панели и финальные страницы |
| `08_rules/` | Производственный процесс, правила канона и визуального постоянства |

## Порядок работы

1. Фиксировать источник и его версию.
2. Переносить подтверждённые автором сведения в канонические карточки.
3. Не заполнять пробелы выдуманными фактами; предложения отмечать отдельно.
4. Планировать арки → главы → сцены → панели.
5. Генерировать иллюстрации по утверждённым референсам, затем проверять и собирать вертикальную главу.

См. [правила канона](08_rules/CANON.md), [производственный процесс](08_rules/WORKFLOW.md) и [реестр источников](01_sources/README.md).

**Важно:** исходные DOCX получены в беседе, но не считаются загруженными в репозиторий, пока их реальные бинарные файлы не появятся в `01_sources/originals/`.
